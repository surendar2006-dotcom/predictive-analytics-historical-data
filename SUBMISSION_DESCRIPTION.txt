Predictive Analytics Using Historical Data is a Python project that forecasts future monthly sales using a Linear Regression model. It demonstrates data cleaning, preprocessing, chronological train-test splitting, model evaluation with MAE, RMSE, and R-squared, and visualization of historical and predicted trends. The project includes a sample dataset, executable source code, a six-month forecast CSV, evaluation metrics, charts, and a project report. The included data is synthetic and intended for educational purposes. The model provides a simple baseline and can be improved with real business data and time-series techniques.
